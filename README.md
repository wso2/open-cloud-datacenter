This branch contains tools created for the [Open Cloud Datacenter](https://github.com/wso2/open-cloud-datacenter) project. It is intended for practical utilities tools that help with operating, troubleshooting, and maintaining the project.

The Open Cloud Datacenter project provides an open, modular platform for turning on-premises infrastructure into a self-service cloud. The tools in this branch support the people building and running that platform.

## Project Overview

This is a supporting branch, not a standalone runtime or deployment. The toolset is currently small and will grow as new utilities are created for the project. Each tool should include enough documentation to explain its purpose, inputs, and expected output.

When adding or changing a tool, keep it portable where possible and document
any project-specific dependencies.
